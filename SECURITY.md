# Security

Please do not report vulnerabilities in this project through a public GitHub
issue.

To report a vulnerability privately, select **Report a vulnerability** on the
[GitHub Security Advisories page](https://github.com/tantosec/tturl/security/advisories),
or email [research@tantosec.com](mailto:research@tantosec.com).

Include the affected version, impact, and enough detail to reproduce the issue.
